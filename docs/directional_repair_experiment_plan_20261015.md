## 共同定义与固定条件

对同一完整 prefix h，p⁻、p⁺ 分别是周期起点与终点 actor 的下一个 token 分布；q₀ 是冻结 drafter 在 **终点 actor 特征 F⁺ 与终点输出头** 下的分布；qφ 是待训练 drafter。

令 Δp=p⁺−p⁻，逐 token 定义：

```
s = min(relu(-Δp), relu(q₀ - p⁺))
u = min(relu( Δp), relu(p⁺ - q₀))
S = sum(s); U = sum(u); m = min(S, U)
TV = 0.5 * sum(abs(p⁺ - q₀))
r_dir = q₀ - η*m*s/S + η*m*u/U
ρ = η*m/TV
r_all = (1-ρ)*q₀ + ρ*p⁺
```

只在两侧非空且 m 高于数值噪声的共同位置使用附加损失。m=0、单侧为空或无效位置统一跳过；不补随机位置，不启用回退蒸馏。ρ 的计算先处理 TV=0，禁止除零；超出理论边界须报错，不静默归一化修正。

| 固定项 | 计划值 / 规则 |
| --- | --- |
| actor 参照 | 首轮原始 actor0 → 完成 5 次更新的 actor5；四组训练期间冻结 actor5 |
| 模型 | 原始 Qwen3-8B、原始 dspark_qwen3_8b_block7；新 actor 特征与输出头固定 |
| actor 数据 | 原 DAPO 训练文件；预先排除验证题，记录数据哈希、排除清单、采样 seed=17 |
| 候选与选择 | 同一份 rollout/prefix 面板；每样本最多 128 个首位候选，按 m 取最多 32 个 |
| 窗口与采集预算 | 512 窗口；每副本采集上限 16,384 token，记录实际行数与样本数 |
| 并行 | 沿用 16 NPU、TP/SP=4；统计按 4 个独立数据副本去重 |
| 基础损失 | L₀ = mean(response-K3) + 0.1 × mean(首拒 replacement-token CE)，独立归一化；关闭 rejected-K3 |
| drafter LR / 步数 | LR=1e-5，constant、无 warmup；主终点 5 步，诊断点 0/1/3/5/10 |
| 公平性 | 初始模型、Adam、scheduler、RNG、样本抽取序列、位置集合及 mask 相同 |

沿用最近四副本配置时，目标是合计 2,048 个不同选中位置；若合法位置不足，四组一起缩减，不补采。记录“候选位置数、选中不同位置数、实际位置训练次数、独立响应数”四个分母，不把多 rank 重复计数当成更多样本。

## 1. 配对修复目标诊断

### 1.1 最小探针

先取约 512 个配对候选位置，使用完整词表、FP32 概率计算；通过正确性检查后扩大到完整候选池。本阶段不更新 drafter。

- 所有候选记录 S、U、m、TV、TV(p⁻,p⁺)、actor 熵、回答绝对位置、原 trace 的接受情况。
- 同时汇总 m/TV 的逐位置分布、sum(m)/sum(TV)、m 超过噪声阈值的比例；明确条件分母。
- 计算 η=0.5 和 1 的 r_dir、r_all，验证非负、归一化与两种目标的 TV 改善均为 ηm。
- 在少量相同 prefix 上记录 q(F⁻) 与 q(F⁺)，分离 actor 特征变化造成的 drafter 输出漂移。
- 做相同模型重复前向与 p⁻=p⁺ 的空变化检查。用重复前向的伪 m 分布设噪声阈值并记录，不能通过放大 β 把数值噪声当信号。

### 1.2 与 greedy 提议对齐

当前 drafter 为 greedy。记录 q₀、r_dir、r_all 的 top-1 token、top-1 margin、top-1 翻转比例，以及：

```
Δa_target = p⁺_deploy(argmax r) - p⁺_deploy(argmax q₀)
```

p⁺_deploy 应包含实际 temperature、top-p 等采样处理。训练目标的原始软分布与部署接受分布分别保存定义。不得将软分布 TV 的下降直接写成 greedy 接受率提升。

该指标是目标分布的局部诊断，不是神经网络更新的收益保证；若不翻转 top-1，仍记录 margin 变化，避免误判为绝对不可训练。若只改善 TV、没有有利提议变化，则将训练阶段定位为可学习性验证，暂不扩大在线实验。

交付：`paired_panel_manifest.json`、`candidate_scores.parquet`、`target_diagnostics.json`、分位数及位置分布图。所有图表区分全部候选与被选位置。

## 2. 同位置四组损失对照

本阶段四组固定使用 **同一套 top-m 位置**，不同时切换随机/top-TV，也不改采集预算。

| 组别 | 总损失 | 检验目的 |
| --- | --- | --- |
| A | L₀ | 同位置的原损失基线 |
| B | L₀ + β KL(sg(p⁺) || qφ) | 直接增加当前 actor 全分布蒸馏 |
| C | L₀ + β KL(sg(r_dir) || qφ) | 定向处理新增失配 |
| D | L₀ + β KL(sg(r_all) || qφ) | 相同 ηm 搬运量，按全部当前失配分配 |

C−D 是主要比较；C−B 判断实际选型价值，C−A 判断相对现有训练的增益。所有附加 KL 均按同一有效首位集合的全局位置均值归一化，不再按 m 加权，避免引入第二种筛选因素。

### 2.1 参数与运行次序

1. 首轮训练 η=1。η=0.5 先只做目标诊断；若 η=1 出现方向过冲或拟合不稳，再补 C/D 的 η=0.5 对照。
2. 在同一个校准批次上测共享可训练参数的全局梯度范数。以 C 附加项约占 L₀ 梯度范数的 25% 为 β 初始标定目标，记录实际 β；B/C/D 使用同一 β，并记录三者实际梯度比与夹角。梯度过小或 L₀ 近零时停止标定检查原因，不无限放大 β。
3. q₀ 与两个修复目标在本轮所有优化步骤内固定并停止梯度。训练时不能随 qφ 改变而刷新目标。
4. A/B/C/D 各自从同一模型与优化器状态出发，使用同一批次序列；在 0/1/3/5/10 步保留指标。第 10 步是过拟合/深度诊断，不取代预先指定的第 5 步主要终点。
5. 首轮固定随机种子及验证顺序表；复验时轮换训练臂和 rollout 顺序。若 B 的梯度比远高于 C/D，不能把 B/C 差异全部解释为目标优劣；只在有必要时补 B 的梯度幅度匹配对照。

### 2.2 指标与验证

每个诊断点在训练位置和独立配对 prefix 上分别测：KL、对 p⁺ 的 TV、固定原 surplus/deficit 集合中的概率变化、方向正确比例、top-1 翻转及 p⁺_deploy 给实际提议的概率。局部梯度符号检查与共享网络参数更新后的实际概率变化分开报告。

独立新 rollout：至少 256 道去重题目。先清点原验证集；若仍只有 30 道独立题，从原始 DAPO 中预先留出并从 actor 训练源排除同题记录，使用去重哈希验证零交集。不能用同题重复生成凑“256 道”。验证选择与 β 校准不使用最终评估结果。

先做共同零更新基线和四组第 5 步 rollout；局部结果支持时再补第 3/10 步。报告接受长度、各 block 位置接受情况、输出长度、截断率、正确率（有可靠答案时）、总输出 token/总生成时间。负载测速可以重复题目，但统计置信区间按独立题聚合；验证顺序采用配对交叉并记录原始单次时间。

成本单独记录：旧特征/输出头额外保留、新 actor 配对前向、m/TV 打分、目标构造、数据传输、训练、发布。用于在线可行性判断的成本是相对基础方案的实际增量，不把四臂离线缓存准备总成本直接算到单臂上线成本。

### 2.3 继续条件与解释

- C 优于 A、但不优于 D：尚无定向选择的独立收益；必要时补 q₀ 自蒸馏对照，检查是否主要是约束更新。
- C 优于 D、但不优于 B：方向选择有价值，但直接蒸馏可能更简单划算。
- C 在独立位置和 rollout 上均优于 B/D，且第 3–5 步即可获益：扩展到第二份独立采集数据及不同 actor 周期。
- 区间跨零或方向不一致：报告不确定性，不按某个最高单次 TPS 选优；停止扩大完整在线训练。
- 最终在线门槛：在下一次 drafter 更新前的五个 actor step 内，实际 rollout 节省时间应覆盖额外采集、训练与发布成本；任务质量不得出现明确退化。

首轮只做 actor0→5，后续再考虑 45→50、95→100 等真实五步周期；没有配对起点数据时重新采集，不使用 actor50→100 代替周期变化。

## 3. 配对采集与训练接入验证

### 3.1 数据版本与对齐

每条记录必须包含：完整 prefix 哈希、样本 ID、绝对预测位置、窗口范围、block 首位索引、actor 起止 step/权重标识、F⁺ 标识、输出头标识、q₀ 权重标识、采样配置、旧 trace 来源 actor。

首周期在原始 actor 更新前保留 prefix 与旧 actor 特征/输出头；周期末在完全相同 prefix 上重新计算 p⁺ 与 F⁺。消费完旧面板后，再用本周期训练样本构造下一周期面板并用当时 actor 重新前向，不能把先前缓存的旧特征直接标记为新参照。

原 m 打分对应 draft block 首位。新增软目标损失只接入同一首位 logits；基础 K3/CE 的既有位置范围保持不变。首拒位置可能在 block 后续位置，不能把它与“block 首位”混用。

四臂基础 response teacher 路径一致。原 trace 的首拒 CE 标签统一固定并保留来源版本；即使 F⁺ 已刷新，也不能宣称历史 replacement token 是新 actor 重新生成的监督。

### 3.2 必须通过的检查

| 层级 | 检查 | 通过标准 |
| --- | --- | --- |
| 数学 | 概率非负、归一化、质量守恒、m≤min(TV(p⁻,p⁺),TV(p⁺,q₀))、目标 TV 改善 | FP32 容差预先固定；异常报错，不静默重归一化 |
| 位置 | 完整 prefix、绝对位置、旧/新 hidden 行与预测 token 对齐 | 一一匹配；窗口相同不足以替代完整 prefix 相同 |
| 起点 | 缓存 q₀ 与训练前 qφ 在相同 F⁺/输出头下比较 | 确定性前向在预设容差内一致；检查 train/eval/dropout 差异 |
| 梯度 | 软 CE 与 KL 梯度一致；qφ=q₀ 时方向符合 ηm(s/S−u/U) | logits 级数值验证；teacher、目标、冻结 head 无梯度 |
| 空变化 | p⁻=p⁺、m=0、β=0 | 修复项跳过；β=0 恢复基础路径，不改变有效归一化 |
| 并行 | SP 组候选/选位/目标哈希一致；DP 各自数据正常不同 | 无缺 rank、无重复计入预算；全局分母正确 |
| 回滚 | 模型、Adam、scheduler、步数、RNG、已发布权重 | 四臂起点一致，结束后精确回滚；失败立即停止后续臂 |
| 隔离 | 验证 prompt 与训练 prompt 去重哈希 | 交集为空，报告真正独立题目数 |

默认数值检查参考：概率和误差 ≤1e-5、TV 恒等式绝对误差 ≤1e-5；实际容差先用确定性 FP32 小例与 NPU 重复前向确认并写入 manifest。BF16 概率直接相减不作为 m 的精度基准。

### 3.3 接入顺序与产物管理

1. 扩展 `directional_sampling.py` 的目标构造与数学检查；先完成纯张量验证。
2. 扩展配对采集：选中后保存 p⁻/p⁺/q₀ 或可精确重建三者的最小信息；候选池只保存标量统计，避免全池完整词表长期落盘。
3. 扩展 `dspark_trainer_backend.py` 的首位软目标项，并保持默认关闭；加 β=0、mask、归一化和并行检查。
4. 扩展现有冻结对照 worker/trainer：同一份批数据供四臂使用，独立目标文件按 sample/position 索引；缓存按 SP 副本去重。
5. 先做真实 NPU 单批单步检查，再做四臂 5 步主实验；检查通过后补第 10 步诊断与独立 rollout。

现有 r4 批缓存没有完整 p⁻，不能仅凭它重建本计划的修复目标；需要新配对采集。原始模型、数据集和 checkpoints 中的权重继续作为可用输入。

短期保留：所选位置的配对分布、共同批数据、初始状态校验信息，以及四臂第 5 步 drafter。长期保留：manifest、配置、标量候选统计、逐题验证指标、汇总报告和必要权重。每个 SP 组只保留一份等价批缓存；不长期保存 16 rank 重复 hidden-state 文件。
